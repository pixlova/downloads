# Pixlova — Téléchargements

Fichiers d’installation du Player natif Pixlova (Windows, Linux, Raspberry Pi), dans les [Releases](https://github.com/pixlova/downloads/releases) de ce dépôt.

- Page de téléchargement : https://www.pixlova.com/fr/telecharger/ (English: https://www.pixlova.com/download/)
- Guides d’installation : https://docs.pixlova.com

Les releases sont publiées automatiquement depuis le dépôt du Player (workflow « Téléchargements publics ») ; ne pas les modifier à la main. Chaque release contient un fichier `SHA256SUMS` pour vérifier les fichiers.
